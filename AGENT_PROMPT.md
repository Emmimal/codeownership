Implement the notes and folders feature in this repository.

The application must support:

- creating notes
- creating folders
- assigning notes to folders
- removing notes from folders
- listing notes in a folder
- deleting folders
- retrieving notes

A note may belong to more than one folder.

Complete the implementation using the interfaces already provided in the repository. The README describes the public functions.

Run the provided test suite and make sure it passes:

    python -m unittest discover -s tests/visible

You may modify the implementation files and add internal helpers as needed. Do not modify the public function signatures, the `app/__init__.py` exports, or anything under `tests/`.
